# 2026-10-03

## mobile 播放音质设置接入实际播放链路

- 背景：设置页「内网/外网播放音质」只存值不生效；播放路径硬编码 lossless。
- 改动（apps/mobile）：
  - `src/context/SettingsContext.tsx`：internal/externalPlaybackQuality 默认值 high/standard → lossless（已持久化的用户选择不受影响）。
  - `src/utils/playbackQuality.ts`：新增 `getPlaybackQualityPreferenceSync()`，基于 `networkMode.ts` 的 `isInternalNetworkSync()`（AuthContext 在服务器切换时刷新）同步选档，供起播路径（不能 await）使用。
  - `src/context/PlayerContext.tsx`：新增 `qualitySettingsRef` 快照（防 widget/同步事件旧闭包拿到过期设置）；`playTrack` 的 `initialQuality` 与 `playTrackList` 的 `listQuality` 改为 `preferredQuality ?? getPlaybackQualityPreferenceSync(...)`；`loadPlaybackState` 恢复路径向 resolveTrackUri 透传 quality。
  - `src/services/trackResolver.ts`：ResolveOptions 新增 `quality`；音乐播放 URI 走 `buildTrackPlaybackUrl(track, quality)`，有声书不变；**后台缓存下载恒用 originalUri（原音质）**——缓存按 track.id+path 去重，缓存转码档会污染后续原音质播放。
- 服务端 `/track/stream/:id?quality=` 早已支持，非法档位自动回落 defaultQuality，客户端可放心透传。
- 边界：命中本地缓存时播缓存文件（原音质），设置不生效属预期；播放中途不切 URL（避免重新缓冲），设置对下一首起生效。
