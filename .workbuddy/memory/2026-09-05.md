## WidgetIcon 缩放修复（根因解决）

- 用户反馈：hm 小部件按钮改了一天 size 都没变化，图标永远特别小。
- 根因：`WidgetIcon.ets` 的 Path 组件只设了 `.width(size)/.height(size)`，没设缩放。ArkUI Path 坐标是绝对 1:1 映射，width/height 只改容器尺寸、不缩放 path 图形，所有图标永远以 24vp 渲染。
- 尝试 `.viewPort({x:0,y:0,width:24,height:24})` → 编译报错 `Property 'viewPort' does not exist on type 'PathAttribute'`（API 24 不支持）。
- 尝试 `.scale({x:size/24,y:size/24})` → 构建通过但用户反馈大小仍然没变，说明 `.scale()` 变换在卡片渲染管线不生效。
- 最终方案：坐标预缩放——commands() 用模板字符串嵌数学表达式把 24×24 path 坐标乘以 size/24（如 `` `M${8*size/24} ${5*size/24}v${14*size/24}...` ``），消除对渲染时变换的依赖。构建验证通过：`assembleHap BUILD SUCCESSFUL in 6s`。
