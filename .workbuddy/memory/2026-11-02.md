# 2026-11-02

## mobile 播放详情页播放数秒闪退（UI 主题插件 vinyl 封面）

- 现象：Android 真机激活 UI 主题插件（coverStyle=vinyl）后，播放详情页播放数秒闪退。
- 定位：adb logcat -b crash 抓到 `TypeError: undefined is not a function at VinylCoverTsx2`，发生在 worklets `AnimationFrameCallback.onAnimationFrame`（UI 线程动画帧回调里 JS 异常，无 RN 错误边界 → 直接杀进程）。
- 根因：`apps/mobile/src/components/VinylCover.tsx` 的 `spin` worklet 在 withTiming 完成回调里递归调用自身。worklet 闭包无法把「组件内的 worklet 引用」序列化到 UI 线程（拿到 undefined），动画跑完一圈回调触发即崩。
- 修复：改为 `withRepeat(withTiming(current+360, {duration:8000, linear}), -1, false)`，启动前先把 `rotation.value` 归一化到 [0,360)（视觉角度不变，withRepeat 每轮从 startValue 重转一圈）；暂停仍 cancelAnimation 停在当前帧。已验证 reanimated 4.1.6 repeat.ts 源码：reverse=false 时每轮从 animation.startValue 重启内层动画。
- **教训（通用）**：Reanimated worklet 内禁止递归引用自身/同组件其他 worklet；无限循环动画一律用 withRepeat，不要手写回调递归。
- 验证路径：手机装的是 release 包（v1.2.7，不可 debug），改动为纯 JS，gradle assembleRelease 重打包后 adb install -r 覆盖安装验证。
