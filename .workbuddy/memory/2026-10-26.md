## desktop 专辑/艺术家列表页封面自适应缩放（对齐首页方案）
- 需求：Category（专辑列表）、ArtistList（艺术家列表）封面缩放与首页一致——空间够时自然尺寸，放不下时等比缩小，每行最少个数与首页一致（专辑 4 / 艺术家 5）。
- 新增共用 hook `apps/desktop/src/hooks/useAdaptiveCoverSize.ts`：入参 containerRef + {naturalSize, gap, minCount, padding=60, minSize=60}；ResizeObserver 实测容器 clientWidth（不含滚动条），fitCount >= minCount 用自然尺寸，否则 `floor((avail - gap*(minCount-1))/minCount) - 1` 并夹 [minSize, naturalSize]；未测量时回退 window.innerWidth - 200 - padding 估算。只改尺寸、不触发数据重拉（列表页是无限滚动，本身无需按宽度取数）。
- Category：Cover/Cover.Skeleton 传 `size={coverSize}`（170/4 个）。
- ArtistList：Avatar `size={coverSize}`（120/5 个），名字容器 width 从写死 100px 改为 coverSize，骨架屏 Skeleton.Avatar/skeletonCard/skeletonName 同步尺寸。
- **关键认知**：CarMode 的 contentColumn 是 `flex: 1 1 0`，车机模式下页面容器本身就被压缩，实测 clientWidth 已含车机影响，**不要再手动扣媒体栏宽度**。顺手修了 Recommended 的 getAvailableWidth：实测路径跳过一次性的车机扣宽（之前是 window.innerWidth 估算时代的遗留，改 ResizeObserver 后在车机模式双重扣减，封面会缩到 60px 下限）；只有未测量的估算 fallback 保留扣减。
