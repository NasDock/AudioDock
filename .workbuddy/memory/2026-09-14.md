# 2026-09-14

## 小爱音箱弹窗：在线设备列表 + 播放流转（全端）

### 需求
在播放详情页的小爱音箱弹窗里新增「我的在线设备」列表，支持把当前播放流转到同账号下的其他在线设备（电脑/平板/手机/小程序/电视/手表预留），通过现有 WS 架子实时同步。

### 关键改动

**后端（services/api）**
- `Device` 模型新增 `deviceId`（稳定唯一标识）/ `platform` / `lastSeen` 字段，`@@unique([userId, deviceId])`
- `UserService.saveDevice` 改按 `(userId, deviceId)` upsert，新增 `touchDevice`/`getUserDevices`
- `sync.gateway.ts`：WS 握手用 `JwtService.verify(auth.token)` 鉴权；连接/断开广播 `device_online`/`device_offline`；多 socket 同设备正确判离线；新增 `heartbeat`/`transfer_session` 事件；`forwardTransfer()` 供 REST 转发
- 新增 `GET /user/devices`（设备列表）、`POST /user/devices/transfer`（HTTP 流转，供小程序/TV 发起）
- 登录/注册接口透传 `deviceId`/`platform`

**共享层**
- `packages/services`：`Device` 加字段 + `DevicePlatform` 枚举 + `getUserDevices`/`transferSession`（emby/subsonic 返回空桩）
- `packages/ws`：`SocketConnectOptions` 加 `deviceId`/`platform`
- `packages/i18e`：`player.*` 与 `playerPage.*` 两个命名空间都加了 onlineDevices/transfer*/platform_* 等 key（中英）

**mobile（Expo RN）**
- `utils/platform.ts`：`getDevicePlatform()`（phone/tablet）+ `getOrCreateDeviceId()`（AsyncStorage UUID）
- 登录/注册/WS 连接带 deviceId/platform
- `app/player.tsx` 弹窗顶部加「我的设备」区块 + `transfer_session` 发起 + `transfer_received` 接收接管播放（秒单位）

**desktop（Electron/Tauri）**
- `utils/platform.ts`：`getDevicePlatform()`（desktop/web）+ `getOrCreateDeviceId()`（localStorage）
- 登录/注册/WS 连接带 deviceId/platform
- `components/Player/index.tsx` Popover 顶部加在线设备区块 + 流转发起/接收（秒单位）

**harmony（ArkTS）**
- `utils/device.ets`：`getDevicePlatform()` + `getOrCreateDeviceId()`（kvStore）
- **HarmonySocketService 加了 engine.io v4/socket.io v4 协议握手层**（`/socket.io/?EIO=4&transport=websocket`、`0`/`2`/`3`/`4x` 帧处理、心跳 pong、CONNECT auth token、握手超时兜底），原生 WS 直连后端 socket.io gateway，不再协议不匹配
- `features_network/api/device.ets`：`deviceApi.listMyDevices()`
- `PlayerPage.ets` miCastSheet 加在线设备区块（AppIcon 新增 desktop/tablet/tv/watch/cast 图标）
- 流转发起/接收（内部毫秒 → 协议秒换算）
- ArkTS 严格模式坑：对象字面量必须显式 class（SocketConnectOptions/TransferSessionPayload/Record 字面量全部改成 class + new）

**mini（Taro）**
- 登录/注册传 deviceName/deviceId/platform（`platform: 'mini'`）
- `MiDeviceSelector` 加在线设备区块（HTTP 兜底，不接 WS）
- 发起流转走 `POST /user/devices/transfer` REST（mini 无常驻 WS，由后端代为转发）
