## desktop 播放详情页底部封面点击 → 最小化到悬浮 mini 播放器
- 需求确认（AskUserQuestion）：「最小化」= 关闭全屏播放详情页 + 隐藏主窗口 + 弹出悬浮 mini 窗口，不是仅收起 Drawer。
- 链路：`src/components/Player/index.tsx` 的 `renderMiniPlayer(expandable)` 被复用两次 —— 主窗口底部条 `renderMiniPlayer(true)` 的 `songInfo` 点击展开全屏 Drawer；详情页底部 `renderMiniPlayer(false, coverColor)` 的封面原本点击无响应（`expandable && ...` 被短路）。

- Rust 侧 `create_mini_window`（`src-tauri/src/commands.rs`）会 `main.hide()`，mini 与 main 二选一；mini 窗口返回走 `show_main_window`。⚠️ **独立 `src/components/MiniPlayer/index.tsx` 的封面目前没有 onClick**，只有顶栏 `SelectOutlined` 返回按钮能回主窗口 —— 用户口语里「mini 播放器封面可以打开」的前提并不成立，若要真正闭环需另补（注意 macOS 上 container 的 `handleDragMouseDown` 会与点击冲突）。

## 四端：飞牛音乐模式下「我的」收藏 / 听过只展示单曲
- 动机：飞牛适配器 `getFavoriteAlbums` / `getAlbumHistory` 恒返回空列表、专辑收藏写入返回 501，专辑子 tab 是无效入口。desktop 的 `pages/Favorites` / `pages/Listened` 已用 `effectiveViewMode = fnosSource ? "track" : viewMode` + Segmented 只留单曲一项解决，本次把三端对齐该范式。

- 落点：mobile `app/(tabs)/personal.tsx` + `src/components/PlaylistModal.tsx`（播放列表弹窗有同款「收藏/听过 → 专辑」子 tab，一并处理）；mini `src/pages/personal/index.tsx` + `src/components/PlaylistModal/index.tsx`；hm `products/entry/src/main/ets/pages/PersonalPage.ets`（复用文件里已 import 的 `isFnosSource()`，`switchSubTab('album')` 加守卫 + `initData()` 里回落 `track`）。hm 播放页 playlistSheet 本身只有单曲维度、desktop 已是成品，均未改动。
- 判定复用上一轮 `mvSupport.ts` 的 `isFnosSource`：mobile 接 `useAuth().sourceType`；mini 页面传已有 `sourceType` state、弹窗无 state 直接读 storage。
