## hm 横屏封面轮播（堆叠式 1-2-3-2-1）从 0 到收官

1. 初版 coverflow（rotateY 平铺）→ 用户要堆叠式（1:2:3，侧封面只露 1/3），重写。
2. 滑动失效三连修：`.gesture` 输手势竞争 → `.priorityGesture` 仍被隐藏控制条 Block 吃触摸（"一滑就弹控制组"）→ 控制条改 `Visibility.Hidden` 解决。
3. 方向反转：`effPos = pos − offset/step` 符号错 → 改 `pos + offset/step`。
4. 切歌闪烁：ForEach key 含 pos → 节点全重建；改 idx 后 pos 闭包旧值导致「刷新无规则、个数随机」→ transform 改读 `this.view.currentIndex` 现场算。
5. 定版交互：手机横屏移除控制组，封面中心加 64×64 毛玻璃播放键；按钮被 alignContent:Bottom 压底 → 套全尺寸居中容器；容器吞手势 → hitTestBehavior(None)；下半部滑不动 + 按钮点不了 → 手势层 zIndex(1000) 置顶 + 按钮移入 coverFlow Stack 内。
6. 真机验收通过。
