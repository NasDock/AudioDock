## mobile 端手动切歌加载完不自动播放修复

**Bug**：播放 A 时点击 B → 加载中 → 加载结束停在 Stopped，需再点一次播放；A 播完自动切 B 正常。

**根因**（`apps/mobile/src/context/PlayerContext.tsx`）：
- 自动连播走 `skipToNext()` 不打断播放状态所以正常；手动切歌走 `playTrack`（add+skip+remove+play）/ `playTrackList`（setQueue+skip+play），`play()` 意图会被原生队列重建/索引位移吞掉。
- `playTrack` 里 `TrackPlayer.remove(旧队列)` 是 fire-and-forget，与后续 `play()` 竞争导致索引位移。

**修复**：
1. `PlaybackState` 事件兜底：加载结束且原生状态非 Playing/Paused/Buffering/Loading、`isPlaybackRequestPendingRef && pendingPlaybackTrackIdRef === currentTrack.id` 时自动补发 `TrackPlayer.play()`。Paused 不触发故不影响手动暂停；自动连播时 pending 已清空不受影响。
2. `playTrack` 的旧队列 `remove` 从 skip 后（fire-and-forget）挪到 `play()` 之后执行，消除竞态。

**经验**：RNTP 手动切歌路径必须有"加载完成自动补播"兜底，isLoading 纯事件驱动不会重发 play；pendingPlaybackTrackIdRef 就是天然的"播放意图"标志。

## desktop 生产版 DevTools 快捷键（Cmd+Option+I）

**需求**：mac 生产环境查看 desktop 控制台（Tauri 2 / WKWebView，无 Chromium DevTools）。

**临时方案**（不改代码）：Safari → 开发菜单 → 选 AudioDock WKWebView；或 `log stream --process AudioDock`。

**长期方案**（已落地）：
- `Cargo.toml`：tauri features 加 `devtools`（生产版也编译 DevTools API），新增 `tauri-plugin-global-shortcut = "2"`。
- `main.rs`：注册 `tauri_plugin_global_shortcut` 插件 + handler；setup 里同时注册 macOS `Cmd+Opt+I` 和 Windows/Linux `Ctrl+Shift+I`，handler 命中任一即 toggle `main` 窗口的 devtools。
- `capabilities/default.json`：加 `core:webview:allow-internal-toggle-devtools`（前端 invoke 用）。

**坑**：`window.open_devtools()` 在 release 模式下必须开 `devtools` feature，否则编译期被裁剪。

## 播放列表前后 5 首预下载（mobile / desktop / hm 三端）
- **需求**：当前曲目加载完毕后，预下载播放列表中前后各 5 首（共 10 首）；播放列表变化时清空预下载标记重新计算；每次切歌（点击新歌曲）继续触发。
- **mobile**（`PlayerContext.tsx`）：
  - 新增 `preDownloadedIdsRef: Set<string>` 去重标记，`setTrackListState` 时清空（播放列表变化）。
  - `PlaybackActiveTrackChanged` 事件里把原「只预下载下一首」扩展为「前后各 5 首循环触发」，已触发过的跳过，`resolveTrackUri(t, { cacheEnabled, shouldDownload: true })` 后台下载。
  - 所有网络类型都下载（不只 Wi-Fi），流量敏感用户可关闭「边播边缓存」开关。
- **desktop**（`Player/index.tsx`）：
  - 新增 `preDownloadedIdsRef: Set<string>`，`playlist` 变化时清空。
  - 当前曲目 `isPlaying` 时触发预下载：web 模式用 `cacheAudioInBackground(url)`（CacheStorage），Tauri 模式用 `resolveTrackUri(t, { cacheEnabled })`（Rust 本地缓存下载）。
- **hm**（`PlayerStore.ets`）：
  - 新增 `preDownloadedIds: Set<string>`，`playTrackList` / `replaceQueuePreservingCurrent` 时清空。
  - 新增 `triggerPreloadAround(current: Track)`：`loadCurrent` 成功后调用，读 kvStore `cacheEnabled` 开关，前后各 5 首循环，跳过本地文件/已缓存/已触发，其余 `fileCache.downloadAudioFromUrl` 后台下载。
- 验证：mobile/desktop esbuild 语法检查通过；hm `hvigorw assembleHap` 通过。
