## 播放页主题色/安卓模糊 修复实施（2026-11-06 下午）
- 实测确认：NAS /image/dominant-color 返回 rgb(182,160,137)，与本地 v2、desktop canvas(181,159,135) 完全一致 → **取色算法无问题**。该封面实为 640×640 PNG(alpha)，正命中 v2 场景。
- 颜色"浅"的真因：渲染公式。desktop 全屏播放页恒深色（top rgba(cover,.5) → bottom rgba(shade(.22),.94) + 底图 brightness(.75)）；mobile 亮色模式 tint 向白 0.72（默认主题就是 light）→ 洗成 rgb(235,228,222)。
- 安卓"无模糊"真因：expo-image Android 固定 `BlurTransformation(min(r,25), 4)`，sampling=4 先缩 4 倍再模糊。afcb5962 的 48px 小图（量化后 96px）→ 24×24 + 半径25 → 半径超图幅 100% → 糊成均匀色块。**图越小越接近纯色，方向反了**。
- 修复：
  1. API：`/image/optimize` 新增 `blur` 参数（sigma 0<blur≤100，resize 之后再 blur，cacheKey 加 b{blur}）。
  2. mobile：新增 `getBlurredCoverUrl(cover, w=192, sigma=12)`（不走 bucket 量化、强制 optimize）；player.tsx 去掉 blurRadius，加 0.25 黑罩对齐 brightness(.75)，渐变改为 desktop 公式（不分明暗）；`PlayerDetailView` 前景强制 darkColors + `<StatusBar style="light"/>`；ThemeContext 导出 darkColors。
  3. 老服务端忽略 blur 参数 → 降级为清晰 192px（3.5KB），不会白屏。
- 待办：重发 API 镜像 + 重新打 APK。PlayerMoreModal 自带 useTheme，仍走全局亮色（白底弹窗）不受影响。
