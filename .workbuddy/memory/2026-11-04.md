## mobile/hm 播放页背景补高斯模糊层
- 用户实测：取色成功但没有模糊+渐变效果（原来只做了渐变罩层；且旧版渐变 Svg 只靠 style absoluteFill 没显式 width/height props，大概率没渲染）。
- 修复：mobile 用 expo-image（blurRadius=70 + scale 1.2 防边缘露底，对齐 desktop blur(80px)）打底 + Svg 渐变罩层加显式 width/height="100%"；hm 用 ArkUI Image .blur(70).scale(1.2) + linearGradient 罩层（angle 70 ≈ CSS 160deg）。
- 两端结构统一为：模糊封面层 + 主题色渐变罩层（插件定义背景时整体不渲染）。

## 播放页背景二次修复：主题色主导 + 渐变 + 高斯模糊（第二轮）
- 用户反馈：hm 视觉是"封面打底+模糊层"主题色不突出；mobile 仍纯色/有时控制组区域发白。
- 根因：① mobile Svg 尺寸用 "100%" 百分比字符串在 Android 上不生效（**必须显式像素数字，对齐 VinylCover 写法**）→ 渐变整层丢；② 背景层 gated 在 `coverColor !== null`，旧服务端/外链封面 → null → 整层不渲染退纯色（亮色=白底）；③ 渐变罩层透明度太低（亮色 0.3/暗色顶部 0.5），模糊封面视觉主导；④ 横屏悬浮控制条写死不透明 themeBackground 白块。
- 修复（两端统一，对齐 desktop「模糊封面 + 近不透明主题色渐变」）：模糊封面层**有封面就渲染**（不依赖取色成功）；渐变近不透明——暗色 `rgba(coverColor,0.88)→shade(0.28)@0.97`、亮色 `tint(0.62)@0.92→tint(0.38)@0.96`（tint=向白混合，两端 utils/dominantColor 新增）；取色失败退中性遮罩（暗 黑0.35→0.85 / 亮 白0.55→0.9，desktop 同款兜底）；控制条仅插件定义背景时保留实底。
- hm：渐变两端色收敛为 bgTintTop()/bgTintBottom() 私有方法（@Builder 内禁 const，别在 builder 里算）；透明占位用 '#00000000' 而非 Color.Transparent（避开 ArkTS 三元联合类型坑）。
- 验证：mobile tsc 改动文件零报错；hm assembleHap BUILD SUCCESSFUL + harmony-cleanup.sh ✓。

## hm 播放页背景三轮修复：沉浸系统区 + backdropBlur 真磨砂 + 三段渐变
- 用户实测反馈：磨砂质感弱、状态栏白色不沉浸、底部小横条区域透出旧效果、渐变看不出。
- 根因：① 背景层画在外层 Column 的 padding（状态栏/小横条避让）**之内**，系统区由 ptBackground 白底填充；② 近不透明渐变（0.88~0.97）把模糊封面层盖死 → 磨砂透不出；③ 两段渐变两端明度接近 → 看不出渐变。
- 修复：
  - build() 重构为外层 Stack：背景层全屏铺满（含状态栏/小横条），内容 Column 保留 padding 避让；LocalizedContent 内旧背景层删除。
  - 罩层改 `.backdropBlur(80)` 实时磨砂（封面 Image 去掉 .blur 预模糊，保留 scale 1.2 防边缘采样露底）+ **三段渐变**（bgTintTop/Mid/Bottom，透明度降到 0.55~0.92 让磨砂透出，明度差拉开）。
  - systemBar.ets 新增 `applyPlayerSystemBar(mode)`：statusBar/navigationBar 透明 `#00000000`，图标反差色（亮色模式黑图标/暗色白图标）；PlayerPage onPageShow 调它，onPageHide + aboutToDisappear 调 applySystemBar 恢复。
- 验证：assembleHap BUILD SUCCESSFUL + harmony-cleanup.sh ✓。

### 三轮补漏：中间内容区被白色盖住
- 原因：LocalizedContent 根 Stack 自带 `.backgroundColor(ptBackground())`——背景层原来在它内部（背景画在子组件之下不冲突），上移到 build() 外层 Stack 后这层正好盖住中间内容区（顶/底 padding 避让区无此层所以正常）。
- 修复：删除该 backgroundColor（外层 Stack 已有同款 ptBackground 兜底，插件背景场景同样由外层兜）。
