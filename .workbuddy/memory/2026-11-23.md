## desktop header 刷新按钮扩展到列表页
- 需求：点击 header 刷新按钮时，专辑列表（Category `/category`）、艺术家列表（ArtistList `/artists`）、合集类别（Collections `/collections`）也要重新拉取。
- 方案：复用既有 `window` CustomEvent `soundx:refresh-home`（`utils/refreshHome.ts`，Header 的 `requestHomeRefresh()` 派发），三个页面各自 `onHomeRefresh` 订阅；照搬 Recommended 的 `refreshRef` 模式持有最新回调，`useEffect([])` 只订阅一次，返回的清理函数自动解绑。
- Category / ArtistList：回调调 `useInfiniteScroll` 的 `reload()`（从第一页重拉并覆盖 zustand 缓存），同时 `scrollTop=0` + `setScroll(key, 0)`，避免重拉第一页后停在旧滚动位置。
- Collections：回调调 `loadCollections()`，保留 `mode === TrackType.AUDIOBOOK` 守卫（避免 MUSIC 模式误请求）。
- 更新 `utils/refreshHome.ts` 注释为全局刷新（原注释只写首页）。
- 验证：`pnpm --dir apps/desktop exec tsc -b --pretty false` 通过；eslint 跑不起来（仓库缺 `typescript-eslint` 依赖，既有问题）。
- 备忘：Header 刷新按钮从 `window.location.reload()` 改为事件广播始于 commit ee6ab2de，此前只有 Recommended 订阅，所以不在首页点击无效果。
