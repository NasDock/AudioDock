# 2026-11-27

## 新增绿联音乐（UGOS Pro com.ugreen.music）数据源（packages + desktop 完成）

### 接口探测结论（实测 UGOS Pro 1.15.1.0127，文档 docs/ugreen-music-api.md）
- 网关 `/ugreen/v1`，信封 `{code,msg,data}`，200 成功。**CORS 全开放**（`*`），desktop web 直连无需代理。
- 登录：`POST /verify/check {username}` → 响应头 `X-Rsa-Token`（base64 PEM 公钥，每次轮换）→ RSA PKCS#1 v1.5 加密密码 → `POST /verify/login` → `data.token`（api_token）。
- 鉴权 = **query `?token=`**（所有 API + 媒体地址）。媒体 `get_file?file_path=` 自带凭据、支持 Range 206 → **无需媒体代理**（类 Subsonic）。
- 歌词：`song/info` 的 `music_file.lyric_url`，列表不带 → 单曲懒加载（同飞牛）。
- 坑：AI 搜索 `/music/search/by_type/ai` 只认 `sort_type=0`（传 1 静默返回空）；`singer` 详情同理且 **page_size 上限 200**（300 报 1005）；`collect/v2`、`songlist/by_id/v2` 不接受 sort_type=0；歌单 add/modify 用嵌套 `{songlist:{...}}`；收藏 `{audio_id_arr}`/取消 `{del_type:2,audio_collect_id_arr}`；写历史 `recently_played/add {audio_id}`。
- sort_type 值：0 添加时间/1 名称/2 歌手/3 碟号/4 年份/6 收藏时间/7 加入歌单时间。
- 歌手内全部曲目：singer 详情只返回按专辑拆分的 album_arr → 逐专辑 `album/v2` 聚合；曲目搜索不匹配歌手名。
- 无有声书模式、无推荐（最近添加模拟）、无搜索历史（端侧 FnosSearchRecordAdapter("ugreen") 复用）、无注册。

### 环境备忘
- Bash cwd 每次调用重置到仓库根，`rm -rf dist`/`pnpm build` 必须用绝对路径（本次误删了根级 dist/ 空目录，git 确认无影响）。
- WorkBuddy 沙箱 shim 拦截 father 的 dist 清理步骤：先手动 `rm -rf packages/services/dist` 再 build。
- 本机代理环境变量会让 node axios ECONNRESET：node 冒烟要 `env -u http_proxy ...`。
- macOS BSD grep 不支持 `{n,m}` 重复量词（报错），分析 minified JS 用 node 正则代替。
