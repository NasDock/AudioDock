## HM 桌面歌词重构：自建悬浮窗 → AVSession 系统歌词组件（推翻 10-27 第一版方案）

用户指出 HM 端实现方式错误，要求按华为官方文档 doccenter-capabilities/avsession-desktop-lyrics 重构。

### 核心结论
- HM 桌面歌词 = 系统承载的 AVSession 歌词组件（API 23+）：应用**不自建窗口**、**无需 SYSTEM_FLOAT_WINDOW 权限**。
- **官方明确系统歌词组件暂不支持自定义样式**——字号/颜色/描边在 HM 端砍除，仅 mobile Android 自建悬浮窗保留样式设置。
- 歌词下发走 `AVMetadata.lyric`（Simple LRC 原文，**UTF-8 字节必须 < 40960**；指南明确"元数据必须包含 lyric 否则桌面歌词不生效"）。歌词行切换由系统按持续上报的 AVPlaybackState 进度自动完成，不需要应用侧 setLyricsText 同步。

### Provider 侧 API（精确签名）
- 模块级 `avSession.isDesktopLyricSupported(): Promise<boolean>`
- `session.enableDesktopLyric(enable)` / `setDesktopLyricVisible(visible)` / `isDesktopLyricVisible()`
- `setDesktopLyricState({isLocked})` / `getDesktopLyricState()`
- `on/offDesktopLyricVisibilityChanged(cb: Callback<boolean>)`、`on/offDesktopLyricStateChanged`
- ⚠️ `onDesktopLyricEnabled` 是 **AVSessionController 侧** API，Provider 侧（本应用）不需要

### 实现要点（avSessionService.ets）
- 新增 `isDesktopLyricSupported()`（缓存检测结果，API<23 调用抛错视为不支持）、`setDesktopLyricEnabled()`（开=enableDesktopLyric(true)+setDesktopLyricVisible(true)，关=先隐藏再禁用）。
- `initDesktopLyric()`：installAVSessionService 第 5 步调用；能力检测→绑监听→按 AppStorage('desktopLyricsEnabled') 恢复；session 未 activate 失败时置 pendingDesktopLyricRestore，activate 完成回调里重试。
- `onDesktopLyricVisibilityChanged` 回调把系统侧可见性回写 AppStorage + kvStore（幂等）→ SettingsPage 开关自动跟随用户在系统歌词上手动关闭的操作。
- `clampLrcForMetadata`：LRC 超 40960B 时按行累计字节截断，保留完整行避免半行解析异常。
- ⚠️ **同 assetId 二次 setAVMetadata 会刷新字段**：封面异步补发的 metaWithCover 必须携带 lyric，否则歌词被清掉——两处 AVMetadata 均加 lyric。

## mobile 桌面歌词：样式设置迁移到悬浮窗遮罩控制面板

需求：样式设置（字号/颜色/描边）从 App 设置页挪到桌面歌词本身——单击歌词弹全屏遮罩层（含设置+关闭开关），再点遮罩隐藏。

### 实现
- 新增 `LyricControlPanel.kt`：全屏半透明遮罩（点空白 dismiss）+ 面板卡片（歌词实时预览复用 FloatingLyricView、字号±(12-36,step2)、文字/描边色板、描边宽度±(0-8,step1)、「打开应用」「关闭歌词」）；中英文标签按 Locale 判断。
- `DesktopLyricsModule.kt`：单击歌词 toggle 面板窗口（独立 MATCH_PARENT TYPE_APPLICATION_OVERLAY，面板 topMargin 避开歌词位置）；样式回调→应用 floatView + SharedPreferences(desktop_lyrics_prefs) 持久化 + sendEvent("DesktopLyricsEvent")；「关闭歌词」→hide+closeRequested 事件；「打开应用」移到面板按钮（原单击拉起 App 行为移除）；show 时先从 prefs 恢复样式；applyStyle(JS→原生)不发事件防循环。
- `desktopLyrics.ts`：EventEmitter 包 addDesktopLyricsEventListener，事件 styleChanged{fontSize,textColor,strokeColor,strokeWidth} / closeRequested。
- `PlayerContext.tsx`：订阅事件→styleChanged 回写 SettingsContext 4 字段、closeRequested→desktopLyricsEnabled=false（updateSetting 会经既有 effect 幂等回灌原生，无循环）。
- `settings.tsx`：删样式 Modal + ActionRow 入口 + 色板常量 + 3 个专用 style；i18e zh-CN/en 删 7 个样式键、desktopLyricsDescription 改为「点击歌词可调整样式或关闭」。
- 验证：tsc --noEmit 通过；JSON 校验通过；settings.tsx 无残留引用。
