# 2026-10-21

## desktop Songs 单曲列表页修复

- `apps/desktop/src/pages/Songs/index.tsx`：
  1. **浮动快捷按钮组（floatingActions）不再随滚动跑掉**：根因是 `.container` 上的 `backdrop-filter: blur(100px)` 会给 `position: fixed` 后代创建包含块，fixed 失效被内容带走。修法：把浮动按钮组用 Fragment 移出滚动容器、作为兄弟节点渲染（CSS 保持 `position: fixed` 不变），代码里留了注释说明原因。
  2. **浮动按钮组新增心动模式按钮**：参照 mobile `FloatingActionButtons` 的顺序（顶部 → 定位 → 心动模式 → 底部），仅 `mode === "MUSIC"` 显示，激活态用 `token.colorPrimary` 底 + `HeartFilled`，未激活 `colorBgElevated` + `HeartOutlined`，title 用 `t("songs.heartbeatMode")`。
- tsc --noEmit 通过；其余（标题行、批量操作等）未动。
